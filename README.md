Nome do app: Minha Biblioteca

Sobre o projeto:

O Minha Biblioteca é um aplicativo Android desenvolvido em Kotlin e Jetpack Compose. Seu objetivo é organizar os livros que o usuário já leu ou deseja ler, permitindo cadastrar novos livros, visualizar a lista e consultar informações detalhadas.
